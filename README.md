# APB-Based SPI Controller

Designed and simulated an APB-based SPI controller using Verilog HDL.

## Features
- FSM-based architecture
- SPI protocol implementation
- Baud rate generator
- Shift register logic

## Tools Used
- Verilog HDL
- ModelSim

## Files Included
- RTL
- Testbench
- Waveforms

## Status
Functional verification completed successfully.
